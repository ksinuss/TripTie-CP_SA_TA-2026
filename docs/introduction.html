Введение

Описание проблемы​

Что нужно для планирования групповой поездки:​

  • Согласовать интересы всех участников (один хочет музеи, другой — развлечения)
  • Потратить много времени на поиск мест, проверку отзывов, построение логистики
  • Учитывать бюджет и погоду

Основные боли пользователей:​

  • Разрозненность информации, сложность учёта интересов всех участников
  • Необходимость вручную искать и анализировать отзывы в картах, на сайтах, в блогах
  • Оформление планов в мессенджерах или таблицах приводит к высоким временным затратам и конфликтам

Текущие альтернативы:​

КатегорияПримеры
Планировщики поездокLambus, TripIt, TripPlan
Картографические сервисыGoogle Maps, Яндекс.Карты
Агрегаторы путешествийЯндекс.Путешествия, Т-Путешествия
Универсальные инструментыExcel, Trello, чаты в мессенджерах

Почему они не решают задачу полностью:​

  1. Агрегируют подтверждения броней, но не помогают с выбором мест
  2. Позволяют сохранять любимые места, но не строить маршрут по дням с учётом времени и интересов
  3. Хранят информацию, но не структурируют её — данные теряются
  4. Не предлагают автоматическую генерацию персонализированного маршрута на основе предпочтений группы и внешних данных

Целевая аудитория​

Сегмент 1: Активные путешественники (20–40 лет)​

Описание:
Люди, которые любят путешествовать компаниями, открывать новые места, активно проводить время. Ищут насыщенные маршруты, нестандартные локации, готовы к спонтанным решениям.

Функции для сегмента:

  • Динамичные маршруты с акцентом на развлечения (клубы, экстрим, пешие прогулки)
  • Учёт популярных среди молодёжи мест, трендовых заведений и событий

Сегмент 2: Семьи с детьми​

Описание:
Родители, путешествующие с детьми. Важно, чтобы маршрут был сбалансирован: места интересны и детям, и взрослым, предусмотрены перерывы на отдых и питание, учтена безопасность и доступность.

Функции для сегмента:

  • Приоритет семейным кафе, паркам, зоопаркам, музеям
  • Планирование времени для перерывов, учёт детских комнат и удобной инфраструктуры

Сегмент 3: Организаторы групповых поездок​

Описание:
Профессионалы, планирующие выезды для коллег, клиентов или участников мероприятий. Задача — подобрать оптимальную программу и оперативно корректировать её под внешние факторы.

Функции для сегмента:

  • Варианты с акцентом на бизнес-центры, конференц-залы, рестораны
  • Интеграция культурно-развлекательных блоков
  • Совместное редактирование и согласование программы

Общие потребности аудитории:​

  • ✅ Быстро составить маршрут
  • ✅ Учесть интересы всех участников
  • ✅ Получить готовый план с учётом времени работы заведений, пробок, погоды
  • ✅ Возможность обсуждать и редактировать маршрут

Бизнес-цели и метрики​

Цели по SMART:​

  1. 500 зарегистрированных пользователей через 6 месяцев после запуска
    Метрика: 2–3 регистрации в день, рост базы для сбора данных

  2. 30% активных пользователей (создавших хотя бы одну поездку) к 31.12.2026
    Метрика: аналитика в приложении, бенчмарк рынка 20–35%

  3. 50 платящих пользователей за первые 6 месяцев после запуска премиум-версии (~30.06.2027)
    Метрика: конверсия ~5% от базы 800–1000 пользователей

  4. Сокращение времени планирования с 6 часов до 1.5 часов к 31.12.2026 (−75%)
    Источник: аналитика по планированию поездок

Ключевые метрики (KPIs):​

  • Количество зарегистрированных пользователей
  • Количество созданных поездок
  • Время на планирование одной поездки
  • Процент вернувшихся пользователей
  • Процент удовлетворённых пользователей (опросы, NPS)

Описание продукта​

Концепция​

Веб-сервис для группового планирования путешествий с автоматической генерацией маршрута на основе:

  • интересов участников
  • бюджета
  • внешних данных (погода, события, рейтинги)

Отличие от аналогов: наличие персонализированных рекомендаций и учёт прошлого опыта пользователя.

Ключевые функции (MVP)​

  • ✅ Регистрация и создание профиля
  • ✅ Создание поездки (город, даты, предпочтения)
  • ✅ Приглашение участников по ссылке/коду
  • ✅ Автоматическая генерация маршрута по дням
  • ✅ Интерактивная карта с метками
  • ✅ Ручное редактирование маршрута
  • ✅ Интеграция с внешними API (погода, места, события)
  • ✅ Сбор обезличенной аналитики

Что НЕ войдёт в MVP:​

  • ❌ Сложный ML с обучением на данных пользователей
  • ❌ Мобильное приложение
  • ❌ Офлайн-режим
  • ❌ Общий чат внутри поездки
  • ❌ Приглашение по email

Риски и стратегии​

Технические риски​

РискВероятностьВлияниеСтратегия
Сложность интеграции с API~70%ВысокоеПереключиться на запасные API
Лимиты запросов~60%СреднееКэширование, переход на платный тариф
Низкое качество данных~50%СреднееМеханизм репортов, комбинация источников

Рыночные риски​

РискВероятностьВлияниеСтратегия
Появление сильного конкурента~40%ВысокоеУскорить разработку уникальных фич, фокус на сообщество
Нежелание платить за премиум~50%ВысокоеПересмотр ценовой модели, реферальная программа

Организационные риски​

РискВероятностьВлияниеСтратегия
Нехватка времени на ML~60%СреднееУпростить ML на старте, использовать готовые библиотеки
Выгорание команды~40%СреднееРетроспективы, реалистичное планирование

Правовые риски​

РискВероятностьВлияниеСтратегия
Нарушение авторских прав~20%ВысокоеЛицензированные источники, удаление запрещённого контента
