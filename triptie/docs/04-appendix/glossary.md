# Глоссарий терминов

| Термин | Определение |
|--------|-------------|
| **Поездка (Trip)** | Контейнер для маршрута: город, даты, участники, предпочтения |
| **Локация (Location)** | Конкретная точка в маршруте: ссылка на место + временной слот + порядок |
| **Место (Place)** | Справочная сущность: название, координаты, рейтинг, фото (кэш внешних данных) |
| **Маршрут дня (DayRoute)** | Упорядоченный список локаций на конкретную дату |
| **Организатор** | Пользователь, создавший поездку; имеет права на редактирование и удаление |
| **Участник** | Пользователь, присоединившийся к поездке; может редактировать маршрут |
| **RouteEngine** | Модуль бэкенда, отвечающий за алгоритм генерации маршрута |
| **Фолбэк** | Резервный механизм на случай недоступности основного источника данных |
| **TTL** | Time To Live — время жизни записи в кэше до принудительной инвалидации |
| **WebSocket** | Протокол двусторонней связи в реальном времени для синхронизации изменений |
