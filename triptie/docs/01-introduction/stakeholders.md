# Стейкхолдеры проекта

## 🔑 Ключевые группы

| Стейкхолдер | Интерес | Влияние | Как вовлекаем |
|-------------|---------|---------|---------------|
| **Пользователи** | Удобный интерфейс, точные рекомендации | Высокое | Опросы, юзабилити-тесты, сбор обратной связи |
| **Разработчики** | Чистая архитектура, понятные требования | Высокое | Документация, код-ревью, тех. долги в бэклоге |
| **Инвесторы** | Рост метрик, путь к монетизации | Среднее | Демонстрации, отчёты по KPI |
| **Владельцы API** (2GIS, Яндекс) | Соблюдение лимитов, корректное использование | Среднее | Документирование интеграций, кэширование |

## 🎭 Матрица RACI (генерация маршрута)

| Задача | Разработчики | Аналитик | Пользователи | Владельцы API |
|--------|-------------|----------|--------------|---------------|
| Сбор требований | I | A/R | C | C |
| Проектирование алгоритма | R | A | C | I |
| Интеграция с внешними API | R | C | I | C |
| Тестирование | R | C | C | I |
| Приёмка функционала | I | A | R | I |

**Легенда**: R = Responsible, A = Accountable, C = Consulted, I = Informed
