# Введение

## 🎯 Проблема

Планирование групповой поездки — это всегда компромисс:

```
❌ Разрозненность информации: карты, отзывы, афиши, погода — в разных местах
❌ Ручная логистика: «как добраться», «сколько времени», «что рядом»
❌ Конфликт интересов: один хочет музеи, другой — тусовки
❌ Потеря контекста: планы в чатах и таблицах трудно актуализировать
```

**Результат**: 4–6 часов на планирование одной поездки, стресс, недовольство участников.

## 💡 Решение

**TripTie** — единый интерфейс для:

1. **Создания поездки**: город, даты, бюджет, предпочтения
2. **Приглашения участников**: ссылка или код
3. **Генерации маршрута**: алгоритм учитывает логистику, погоду, время работы заведений
4. **Совместного редактирования**: изменения видны всем в реальном времени
5. **Визуализации**: интерактивная карта + список по дням

## 👥 Целевая аудитория

| Сегмент | Потребность | Как закрываем |
|---------|-------------|---------------|
| Молодёжь 20–35 лет | Динамичные маршруты, трендовые места | Фильтры «развлечения», «фотогеничные локации» |
| Семьи с детьми | Безопасность, перерывы, детские активности | Фильтры «детская комната», «парки», «короткие переходы» |
| Организаторы | Быстрое согласование, отчётность | Роли, экспорт маршрута, история изменений |

## 🔄 Альтернативы

| Решение | Почему не подходит |
|---------|-------------------|
| Google/Яндекс.Карты | Нет группового планирования, нет персонализации |
| Lambus, TripIt | Агрегируют брони, но не помогают с выбором мест |
| Таблицы + чаты | Нет структуры, легко потерять данные, нет автоматизации |
