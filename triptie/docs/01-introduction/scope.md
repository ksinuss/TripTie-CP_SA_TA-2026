## План развития и ограничения

### Версии продукта:

| Версия | Фокус |
|--------|-------|
| **1.0 (MVP)** | Базовая функциональность: создание поездки, генерация маршрута, карта, редактирование |
| **2.0** | Улучшение рекомендаций на основе истории, отзывы и оценки |
| **3.0** | Приглашение по email, общий чат в поездке |
| **4.0** | Мобильное приложение, офлайн-режим |
| **5.0** | Бронирование билетов, интеграция с календарями |

### Бюджет на запуск MVP (~$10 000):

- API-ключи (карты, погода): $0–100/мес
- Хостинг и БД: $0–20/мес (Free Tier)
- Рассылки: $0–20/мес
- Маркетинг: ~$200/мес
- Команда разработки (наём): основная статья расходов

### Сроки разработки (13 недель):

```
Недели 1–2:   Анализ требований, концепция
Недели 3–5:   Проектирование БД, прототипы интерфейсов
Недели 5–8:   Разработка бэкенда и интеграций
Недели 9–10:  Разработка фронтенда
Недели 10–13: Тестирование, подготовка к релизу
```

### Технологический стек:

- **Backend:** Python / Node.js
- **Frontend:** React
- **БД:** PostgreSQL (Supabase)
- **Инфраструктура:** Docker, Git, Яндекс.Облако / AWS
- **Инструменты:** Figma, Postman, buildin.ai
