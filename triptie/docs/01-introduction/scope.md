# Границы и ограничения (Scope)

## ✅ Что входит в MVP

| Функция | Описание | Приоритет |
|---------|----------|-----------|
| Регистрация/авторизация | Email + пароль, JWT-токены | Must |
| Создание поездки | Город, даты, бюджет, предпочтения | Must |
| Приглашение участников | Ссылка или код, роли (организатор/участник) | Must |
| Генерация маршрута | Алгоритм с учётом логистики, погоды, времени работы | Must |
| Интерактивная карта | Отображение меток, кластеризация | Should |
| Редактирование маршрута | Добавление/удаление/перестановка локаций | Should |
| Совместное редактирование | WebSocket-синхронизация изменений | Could |

## ❌ Что НЕ входит в MVP

| Функция | Причина исключения | Когда вернёмся |
|---------|-------------------|----------------|
| Мобильное приложение | Фокус на веб, ограниченные ресурсы | Версия 4.0 |
| Офлайн-режим | Сложность синхронизации, низкий приоритет | Версия 4.0 |
| Внутренний чат | Можно использовать внешние мессенджеры | Версия 3.0 |
| Платёжная система | Нет монетизации на старте | Версия 2.0 |
| Сложный ML | Достаточно правил + простой эвристики | Версия 2.0 |
| Интеграция с бронированием | Юридические и партнёрские сложности | Версия 5.0 |

## 🔗 Зависимости от внешних систем

| Система | Назначение | Критичность | Фолбэк |
|---------|-----------|-------------|--------|
| 2GIS API | Данные о местах (рейтинг, фото, график) | Высокая | OSM Overpass (без отзывов) |
| Яндекс.Карты / OSM | Отображение карты, геокодинг | Средняя | Переключение между провайдерами |
| Open-Meteo / Яндекс.Погода | Прогноз погоды на даты поездки | Низкая | Кэш + усреднённые климатические данные |
