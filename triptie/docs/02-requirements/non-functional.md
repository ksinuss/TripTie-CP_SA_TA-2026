# Нефункциональные требования (NFR)

## 🚀 Производительность

| Требование | Значение | Приоритет |
|------------|----------|-----------|
| Время генерации маршрута | ≤ 5 сек при 100 одновременных пользователях | Should |
| Время ответа API | ≤ 300 мс для 95% запросов | Should |
| Загрузка страницы | ≤ 2 сек при 3G-соединении | Could |

## 🔒 Безопасность

| Требование | Реализация | Приоритет |
|------------|-----------|-----------|
| Хранение паролей | bcrypt с солью, минимум 12 раундов | Must |
| Передача данных | HTTPS (TLS 1.2+), HSTS | Must |
| Аутентификация | JWT с коротким временем жизни, refresh-токены | Must |
| Защита от перебора | Rate limiting: 5 попыток входа / 15 мин | Should |

## 🌐 Доступность и надёжность

| Требование | Значение | Приоритет |
|------------|----------|-----------|
| Uptime сервиса | 99.5% в месяц (≤ 3.6 ч простоя) | Should |
| Восстановление после сбоя | ≤ 15 минут (RTO) | Could |
| Резервное копирование БД | Ежедневно, хранение 30 дней | Should |

## 🎨 Удобство использования (UX)

| Требование | Критерий | Приоритет |
|------------|----------|-----------|
| Создание поездки | ≤ 6 кликов от главной до подтверждения | Should |
| Генерация маршрута | ≤ 3 клика от страницы поездки до результата | Should |
| Приглашение участника | ≤ 4 клика до получения ссылки | Should |
| Адаптивность | Корректное отображение на мобильных (320px+) | Should |

## 🌍 Совместимость

| Требование | Поддержка | Приоритет |
|------------|-----------|-----------|
| Браузеры | Chrome, Firefox, Safari (последние 2 версии) | Should |
| Мобильные | iOS 14+, Android 10+ (веб-версия) | Could |
| Языки | Русский (MVP), английский (дорожная карта) | Could |

## 📊 Наблюдаемость (MVP — базовая)

| Требование | Реализация | Приоритет |
|------------|-----------|-----------|
| Логирование ошибок | Консоль + файл, уровень ERROR и выше | Must |
| Сбор аналитики | События: регистрация, создание поездки, генерация маршрута | Should |
| Мониторинг доступности | UptimeRobot или аналог, алерт при даунтайме > 5 мин | Could |
