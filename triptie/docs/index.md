# TripTie — Документация проекта

> Веб-сервис для совместного планирования поездок с автоматической генерацией персонализированных маршрутов.

## 🎯 О проекте

**TripTie** помогает группам путешественников быстро согласовать интересы и получить готовый план поездки с учётом:
- предпочтений участников (музеи, природа, развлечения),
- бюджета и времени,
- погоды и логистики,
- рейтингов и отзывов о местах.

## 👥 Для кого

- Друзья, планирующие совместный отпуск
- Семьи с детьми
- Организаторы корпоративных выездов
- Ивент-менеджеры
