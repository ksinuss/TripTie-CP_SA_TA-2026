# Пользовательские интерфейсы и макеты

## Макеты экранов

![Экраны](/img/wireframes.png)

### Экран 1: Создание новой поездки

**Ключевые элементы:**
- Выпадающий список городов
- Встроенный виджет календаря для выбора дат
- Выбор бюджета (появляется при инициации функции)
- Предпочтения по типу мест и питанию

### Экран 2: Просмотр и редактирование маршрута

- **Режим "Список"**

- **Режим "Карта"**

**Функциональность:**
- Переключение между представлениями (список/карта)
- Детальная информация о местах (рейтинг, время, бюджет)
- Редактирование маршрута
- Генерация дня заново

## Переходы между экранами

![Диаграмма переходов](/img/transitions.png)

### Описание потоков

1. **Создание поездки**
   - Главная → `/trips/create` → `/trips/:id`
   
2. **Просмотр маршрута**
   - Главная → `/trips` → `/trips/:id`
   
3. **Редактирование**
   - `/trips/:id` → Режим редактирования → Сохранение → `/trips/:id`
   
4. **Приглашение участников**
   - `/trips/:id` → `/trips/:id/invite` → Копирование ссылки → `/trips/:id`

## Таблица маршрутов

| Путь | Метод | Описание | Экран |
|------|-------|----------|-------|
| `/` | GET | Главная страница | Главная |
| `/trips` | GET | Список всех поездок | Главная |
| `/trips/create` | GET/POST | Создание новой поездки | Экран 1 |
| `/trips/:id` | GET | Просмотр маршрута | Экран 2 |
| `/trips/:id/edit` | GET/PATCH | Редактирование маршрута | Экран 2 (редактирование) |
| `/trips/:id/invite` | GET | Приглашение участников | Модальное окно |
| `/trips/:id/route` | POST | Генерация маршрута | - |
| `/trips/:id/route/:locationId` | DELETE | Удаление локации | - |
