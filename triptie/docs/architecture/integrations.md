# Интеграции с внешними API

## 🗺️ Карты

### Основной выбор: Яндекс.Карты (для РФ)
- **Зачем**: Лучшее покрытие российских городов, детализация зданий, пробок, транспорта
- **Что используем**: JS API для отображения, Geocoding API для поиска адресов
- **Лимиты**: 25 000 запросов/сутки бесплатно
- **Фолбэк**: OpenStreetMap + Leaflet (бесплатно, но меньше деталей)

### На старте (для тестов): OpenStreetMap
- Не требует ключа, нет лимитов
- Покрытие глобальное
- Подходит для прототипа и международных городов

## 🏛️ Места и достопримечательности

### Основной выбор: 2GIS Places API
- **Зачем**: Детальные данные по организациям РФ: рейтинг, отзывы, график работы, фото, атрибуты (Wi-Fi, детская комната)
- **Что запрашиваем**: `name`, `point`, `rating`, `reviews_count`, `photos`, `work_hours`, `categories`
- **Лимиты**: Демо-ключ на 1 месяц, далее — по согласованию
- **Фолбэк**: OSM Overpass API (только базовые теги, без отзывов)

### Пример запроса
```http
GET https://catalog.api.2gis.com/3.0/items
  ?q=музей
  &location=55.751244,37.618423
  &radius=5000
  &fields=items.name,items.point,items.rating,items.photos
  &key=YOUR_KEY
```

## 🌤️ Погода

### На старте: Open-Meteo
- Полностью бесплатно, без ключа
- Прогноз до 16 дней, исторические данные
- Глобальное покрытие

### Для продакшена в РФ: Яндекс.Погода (API)
- Высокая точность для российского климата
- Почасовой прогноз, параметры комфорта
- Доступ по заявке, условия обсуждаются индивидуально

## 🔌 Паттерны интеграции

### 1. Адаптер + кэш
```
Запрос мест
    │
    ▼
[Проверка Redis]
    │
    ├─✅ Есть → вернуть из кэша
    │
    └─❌ Нет → вызвать внешний API
            │
            ▼
    [Сохранить в Redis с TTL]
            │
            ▼
    [Вернуть пользователю]
```

### 2. Circuit Breaker для внешних вызовов
- При 3 последовательных ошибках → временно отключаем провайдер
- Возвращаем фолбэк-данные или сообщение «попробуйте позже»
- Автоматическое восстановление через 5 минут

### 3. Единый интерфейс для провайдеров
```typescript
// Пример абстракции
interface WeatherProvider {
  getForecast(city: string, dates: DateRange): Promise<WeatherData>;
}

// Реализации
class OpenMeteoProvider implements WeatherProvider { ... }
class YandexWeatherProvider implements WeatherProvider { ... }

// Использование
const provider = config.USE_YANDEX ? new YandexWeatherProvider() : new OpenMeteoProvider();
```
