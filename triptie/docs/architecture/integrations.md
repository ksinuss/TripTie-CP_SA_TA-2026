# Интеграция с внешними платформами

## Карты

### Вариант для старта: OpenStreetMap
- Открытая карта мира, поддерживаемая сообществом волонтёров.
- Полностью бесплатная, без ограничений и привязки платёжных данных.

**Почему подходит для MVP:**
- Не требует регистрации, API-ключей или верификации
- Покрытие всех городов РФ и мира
- Нет риска санкционных блокировок
- Активное обновление данных, особенно по туристическим объектам

**Ограничения:**
- Меньшая детализация по зданиям, входам и этажам в некоторых городах
- Геокодинг медленнее и имеет лимиты на публичных серверах
- Нет встроенных данных о пробках и общественном транспорте

**Затраты на интеграцию:**
- Лицензия: бесплатно
- Разработка: подключение через готовую JS-библиотеку
- Инфраструктура: при использовании публичных тайлов — 0₽; при хостинге своих тайлов — до 500₽/мес (VPS)

### Вариант для роста: Яндекс.Карты
- Профессиональный картографический сервис с глубоким покрытием России.

**Почему подходит для продакшена:**
- Высокая детализация: здания, подъезды, пешеходные дорожки, транспорт
- Встроенные инструменты маршрутизации и учёта пробок
- Стабильная работа из РФ, русскоязычная поддержка
- Единая экосистема с другими сервисами Яндекса

**Ограничения:**
- Требуется регистрация в Кабинете разработчика
- Покрытие за пределами РФ/СНГ уступает глобальным аналогам

**Затраты на интеграцию:**
- Получение ключа: бесплатно
- Бесплатный лимит: 25 000 запросов/сутки
- Сверх лимита: от ~260₽ за 1 000 запросов
- Прогноз для MVP (100–500 пользователей/день): укладываемся в бесплатный лимит
- Прогноз при 5 000 активных пользователей: 2 000–5 000₽/мес

## ️Места и достопримечательности

### Основной выбор: 2GIS
- Детальный справочник организаций с актуальными данными, отзывами и фильтрами.
- Сильнейшее покрытие в РФ и СНГ (300+ городов).

**Возможности:**
- Полные карточки мест: название, координаты, рейтинг, отзывы, фото, сайт, график работы, средний чек
- Гибкие фильтры: категория, время работы, район, атрибуты (парковка, детская комната и т.д.)
- Ежедневное обновление данных, частичная модерация
- Русскоязычная поддержка и помощь в интеграции

**Затраты на интеграцию:**
- Демо-доступ: бесплатный ключ на 1 месяц
- Платный тариф: ориентировочно до 15 000₽/мес (~30 000 запросов)
- Оптимизация: кэширование ответов на стороне backend снижает стоимость на 40–60%

## Погода

### Вариант для старта: Open-Meteo
- Открытый сервис прогноза на основе нескольких мировых моделей.
- Полностью бесплатный, без регистрации.

**Почему подходит для MVP:**
- Не требует API-ключа
- Нет лимитов на запросы
- Базовые параметры: температура, осадки, ветер, влажность
- Стабильная работа из РФ

**Ограничения:**
- Меньшая точность для локальных особенностей российского климата
- Нет параметров «ощущается как», УФ-индекса, комфорта

**Затраты на интеграцию:**
- Лицензия и доступ: 0₽
- Разработка: 1 HTTP-запрос на период поездки
- Нагрузка: минимальна, рекомендуется кэшировать ответы (TTL 6–12 ч)

### Вариант для роста: Яндекс.Погода
- Профессиональный прогноз на основе ML и данных с российских метеостанций.

**Почему подходит для продакшена:**
- Высокая точность для территории РФ
- Почасовой прогноз с «ощущается как», вероятностью осадков, УФ-индексом
- Консистентность с картами и маршрутами Яндекса

**Затраты на интеграцию:**
- Тестовый тариф: бесплатно (7 дней, до 10 000 запросов/мес)
- Стартовый платный: ~45 000–54 000₽/мес (до 100 000 запросов, 10-дневный прогноз)
- Плановые затраты при переходе: до 50 000₽/мес

## Как это работает вместе

1. Пользователь создаёт поездку: город, даты, предпочтения, бюджет.
2. Backend запрашивает у **2GIS** список мест, отфильтрованный по категориям и району.
3. Параллельно загружается прогноз от **Open-Meteo** (MVP) или **Яндекс.Погоды** (Prod).
4. Координаты мест передаются на фронтенд, где рендерится карта через **OpenStreetMap** или **Яндекс.Карты**.
5. Алгоритм группирует локации по дням, учитывая:
   - Географическую близость
   - Время работы заведений
   - Погодные условия (дождь → приоритет крытым местам)
6. Пользователь получает готовый маршрут: список по дням + интерактивная карта + сводка по погоде.
