# Архитектура системы TripTie

## Технологический стек

| Слой | Технология | Обоснование |
|------|-----------|-------------|
| **Frontend** | React + TypeScript | Компонентный подход, типизация, богатая экосистема |
| **State Management** | Zustand / Redux Toolkit | Легковесное управление состоянием для совместного редактирования |
| **Карты** | Leaflet (MVP) → Яндекс.Карты (Prod) | Бесплатный старт → детализация по РФ при росте |
| **Backend** | Node.js (Express/Nest) или Python (FastAPI) | Быстрая разработка, хорошая поддержка асинхронности |
| **БД (основная)** | PostgreSQL + Supabase | ACID, JSONB для гибких полей, бесплатный хостинг на старте |
| **Кэш** | Redis | Сессии, кэш маршрутов (TTL 24ч), лимиты API |
| **Очереди** | BullMQ / Celery (опционально) | Асинхронная генерация маршрутов при высокой нагрузке |
| **Хостинг** | Яндекс.Облако / VPS | Работа из РФ, предсказуемая стоимость |
| **CI/CD** | GitHub Actions | Бесплатно для публичных репо, простая настройка деплоя |

## Потоки данных (Data Flow)

### Создание поездки

```
[Пользователь] 
    → (форма: город, даты, предпочтения)
    → [Frontend: POST /api/trips]
    → [Backend: валидация → сохранение в PostgreSQL]
    → [Ответ: 201 Created + ID поездки]
    → [Frontend: редирект на /trips/:id]
```

### Генерация маршрута

```
[Пользователь нажимает "Сгенерировать"]
    → [Frontend: POST /api/trips/:id/route]
    → [Backend: загрузка параметров поездки из БД]
    → [Параллельные запросы:]
        ├─→ [Redis: кэш мест] → если промах → [2GIS API]
        ├─→ [Open-Meteo / Яндекс.Погода: прогноз]
        └─→ [Яндекс.Карты / OSM: гео-данные]
    → [Route Generator: группировка по дням с учётом:]
        • гео-близости
        • времени работы заведений
        • погоды (дождь → крытые места)
        • бизнес-правил (5–7 локаций/день)
    → [Сохранение маршрута в БД + кэширование в Redis]
    → [Ответ: список локаций + координаты]
    → [Frontend: отрисовка списка + карты]
```

### Совместное редактирование (WebSocket)

```
[Участник А меняет маршрут]
    → [Frontend: WebSocket: emit route:change]
    → [Backend: валидация → сохранение в БД]
    → [WebSocket: broadcast route:updated]
    → [Frontend участников Б, В: обновление карты/списка в реальном времени]
```
